Pagina admin non ancora collegata

Serve un'attivazione di 5 minuti su Google, una volta sola.

  1. Apri script.google.com e crea un nuovo progetto.
  2. Incolla il codice del file admin-apps-script.gs e salva.
  3. In Impostazioni progetto → Proprietà script aggiungi ADMIN_PASSWORD con la password scelta.
  4. Esegui il deployment → Nuovo deployment → App web (esegui come: Me, accesso: Chiunque) e copia l'URL /exec.
  5. Inserisci l'URL in config.js alla voce CMS_URL e pubblica il file.
